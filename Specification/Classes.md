# Classes

Classes are contructed through the prefix `class` operator. The operand of the `class` operator is the *candidate set* of the class. The candidate set is the set to which all inhabitants of the class must belong.

A *class* is a *nominal type*. Only those values constructed by through its constructor are inhabitants of the type. The constructor is the class itself.

    myInts = class int


 A class is based on a *candidate set* which restricts the possible inhabitants of the class.
