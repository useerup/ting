## Introductory examples

On hacker news [this post](https://news.ycombinator.com/item?id=46084237) asked that a new languages demo for example solutions written in the language for the following 10 problems:

  1. A compiler for a small language.
  2. A text editor.
  3. An assembler.
  4. A rendering engine for a subset of HTML.
  5. A regex processor.
  6. A ray tracer.
  7. An online store.
  8. A video editor.
  9. A game.
  10. A payroll system.

Well, challenge accepted!
