## Tuples

A tuple is a structured value where each component is known by its position in the tuple.


Examples:

    (1,2,3)     // 3-tuple

    ()          // Zero-tuple

    ( "abc" )   // Just a value; or a 1-tuple


### Special notations

    (,"White")      // a function which creates a tuple (prepends)
    ("White",)      // a function which creates a tuple (appends)

    (,)             // Creates a tuple out of the argument
