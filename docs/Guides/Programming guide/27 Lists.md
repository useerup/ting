## Lists


### List literals

A list literal is an expression list enclosed within `[` and `]`.

Example:

    [1,2,3]

    []          // empty list

    ["a"]       // list of one item



### List functions

    [,1,2,3]    // function which accepts a value and prepends it to the list [1,2,3]

    [1,2,3,]    // function which accepts a value and appends it to the list [1,2,3]

    [,]         // the "listify" function
